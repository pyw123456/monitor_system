一概念
YOLO 是什么
YOLO 是一个“看图片并找东西”的程序。给它一张图片，它会回答三个问题：图片里有什么、目标在哪里、它有多大把握。
输入：一张校园图片输出：person 0.94、car 0.88、fire 0.91
person、car、fire 是类别；0.94、0.88、0.91 是置信度。0.94 可以理解为模型有约 94% 的把握。
数据集是什么
数据集就是“带答案的图片教材”。图片是题目，标注是标准答案。标注会告诉模型目标是什么以及目标在图片中的位置。
COCO 和 COCO8 是什么
COCO 是一套大型通用图片数据集，包含人、车、自行车、狗、背包等常见目标。COCO8 是从 COCO 中选出的 8 张小样例，主要用于快速展示数据格式和训练流程。项目真正使用的是基于完整 COCO 训练完成的 yolov5s 权重，不需要用 COCO8 重新训练。
D-Fire 是什么
D-Fire 是专门包含火焰、烟雾和正常负样本的图片数据集。D-Fire 作者已经提供用该数据集训练完成的 YOLOv5 权重，本实训直接使用该权重。
模型训练是什么
训练就是让模型反复查看图片和标准答案，猜错后调整内部参数。这个过程可能持续数小时甚至更久。训练完成后，会把学习结果保存成权重文件。
图片和标注数据集 → 反复训练 → 生成 .pt 权重文件
pt 文件是什么
.pt 是 PyTorch 模型权重文件，可以理解为模型训练完成后保存下来的“学习成果”。日常识别不需要重新训练，只需要加载 .pt，然后输入图片。
.pt 权重文件 + 新图片 → 推理 → 类别、位置和置信度
推理是什么
推理就是“使用训练好的模型识别新图片”。训练是学习，推理是使用。本实训主要完成推理和系统对接。
二 本实训为什么使用两个模型
COCO 权重擅长通用目标，但没有 fire 和 smoke。D-Fire 权重擅长烟火，但不负责完整的 COCO 类别。因此同一张图片需要依次交给两个模型。
校园图片   ├─ yolov5s-coco.pt  → 人、车、自行车、狗、背包等   └─ yolov5s-dfire.pt → 火焰、烟雾                    ↓             合并 objects                    ↓       POST /api/ai/event                    ↓       Java 后端形成告警并推送页面

# -*- coding: utf-8 -*-"""YOLOv5 双模型校园安防识别服务。"""from pathlib import Pathimport shutilimport threadingimport timeimport requestsimport torchimport uvicornfrom fastapi import FastAPI# 固定目录。ROOT = Path(r"E:\model")YOLOV5_DIR = ROOT / "yolov5"COCO_PT = ROOT / "models" / "yolov5s-coco.pt"DFIRE_PT = ROOT / "models" / "yolov5s-dfire.pt"WATCH_DIR = ROOT / "ai-watch"DONE_DIR = WATCH_DIR / "已检测"# Java 后端接收 AI 结果的接口。BACKEND_URL = "http://127.0.0.1:8080/api/ai/event"# 只处理这些图片格式。IMAGE_SUFFIXES = {".jpg", ".jpeg", ".png"}WATCH_DIR.mkdir(parents=True, exist_ok=True)DONE_DIR.mkdir(parents=True, exist_ok=True)# 同时加载两个现成权重。coco_model = torch.hub.load(    str(YOLOV5_DIR), "custom", path=str(COCO_PT), source="local")dfire_model = torch.hub.load(    str(YOLOV5_DIR), "custom", path=str(DFIRE_PT), source="local")# 两个入口可能同时调用模型，用锁保证依次识别。model_lock = threading.Lock()app = FastAPI(title="YOLOv5 双模型校园安防识别服务")def result_to_objects(result) -&gt; list[dict]:    """把 YOLOv5 结果转换成 Java 后端需要的格式。"""    objects = []    # 每一行依次是 x1、y1、x2、y2、置信度、类别编号。    for row in result.xyxy[0].cpu().tolist():        confidence = float(row[4])        class_id = int(row[5])        # 模型类别名称可能是字典或列表。        class_name = result.names[class_id]        objects.append({            "class": str(class_name).lower(),            "conf": confidence,        })    return objectsdef recognize(image_path: Path) -&gt; list[dict]:    """同一张图片分别交给两个模型，然后合并结果。"""    with model_lock:        coco_result = coco_model(str(image_path))        dfire_result = dfire_model(str(image_path))    coco_objects = result_to_objects(coco_result)    dfire_objects = result_to_objects(dfire_result)    return coco_objects + dfire_objects@app.get("/")def home():    """浏览器访问该接口，检查服务是否启动。"""    return {        "status": "ok",        "cocoModel": str(COCO_PT),        "dfireModel": str(DFIRE_PT),        "watch": str(WATCH_DIR),        "done": str(DONE_DIR),    }@app.get("/detect")def detect(url: str = r"E:\model\yolov5\data\images\bus.jpg"):    """手工识别接口；不传地址时识别 YOLOv5 自带图片。"""    image_path = Path(url)    if not image_path.is_file():        return {"status": "error", "message": "图片不存在"}    return {"status": "ok", "objects": recognize(image_path)}def move_to_done(source: Path) -&gt; Path:    """把图片移动到已检测；重名时在文件名后添加时间。"""    target = DONE_DIR / source.name    if target.exists():        stamp = time.strftime("%Y%m%d_%H%M%S")        target = DONE_DIR / f"{source.stem}_{stamp}{source.suffix}"    shutil.move(str(source), str(target))    return targetdef watch_images():    """每 2 秒检查一次 ai-watch。"""    print(f"[监听] {WATCH_DIR}")    while True:        for image_path in WATCH_DIR.iterdir():            # 忽略文件夹和非图片文件。            if not image_path.is_file():                continue            if image_path.suffix.lower() not in IMAGE_SUFFIXES:                continue            try:                # 使用两个模型识别同一张图片。                objects = recognize(image_path)                # 识别完成后移动图片。                done_path = move_to_done(image_path)                # 按 Java 后端要求组织 JSON。                payload = {                    "image": done_path.name,                    "imagePath": str(done_path),                    "objects": objects,                }                # 提交识别结果。                response = requests.post(                    BACKEND_URL, json=payload, timeout=10                )                print(                    f"[完成] {done_path.name} | "                    f"{objects} | 后端状态 {response.status_code}"                )            except Exception as error:                # 一张图片失败不会停止整个服务。                print(f"[失败] {image_path.name} | {error}")        # 每轮扫描后等待 2 秒。        time.sleep(2)# 在后台启动目录监听。threading.Thread(target=watch_images, daemon=True).start()if __name__ == "__main__":    # 监听 8000 端口，与 Java 后端配置一致。    uvicorn.run(app, host="0.0.0.0", port=8000)

若下载的是“only images and labels”平铺目录，可把下方脚本中的 D:\dfire_src 换成你的解压路径，自动按约 8:2 划分（第 1 条命令分行执行）：
$src = "D:\dfire_src"                      # 你的解压目录
$dst = "E:\model\datasets\DFire"
New-Item -ItemType Directory -Force "$dst\images\train","$dst\images\val","$dst\labels\train","$dst\labels\val" | Out-Null
$imgs = Get-ChildItem $src -Recurse -Include *.jpg,*.jpeg,*.png
$n = 0                                     # 计数
foreach ($img in $imgs) {
$lab = Join-Path $img.DirectoryName ($img.BaseName + ".txt")
if (-not (Test-Path $lab)) { continue }    # 无标注的图跳过
$set = if (($n % 10) -lt 2) { "val" } else { "train" }   # 两成做验证
Copy-Item $img.FullName "$dst\images\$set\" -Force
Copy-Item $lab    "$dst\labels\$set\" -Force
$n++
}
Write-Output "已整理 $n 张带标注图片"
第 3 步  新建配置 E:\model\yolov5\data\DFire.yaml
# D-Fire 烟火数据集：2 类（0=Fire, 1=Smoke）
path: ../datasets/DFire   # 数据集根目录
train: images/train       # 训练集
val: images/val           # 验证集
names:
0: Fire
1: Smoke
第 4 步  开始训练
Set-Location "E:\model\yolov5"
&amp; "E:\model\yolovenv\Scripts\Activate.ps1"
python train.py ^
--data DFire.yaml ^   # D-Fire 数据集配置
--weights yolov5s.pt ^
--epochs 100 ^        # 训练轮数
--batch 8 ^           # 每次处理的图片数
--imgsz 640 ^         # 图片输入尺寸
--device cpu ^        # 用 CPU；有显卡可改 0
--name dfire          # 结果保存到 runs\train\dfire
成功标志：日志出现 Overriding model.yaml nc=80 with nc=2，说明模型已调整为 2 类；权重类别为 Fire、Smoke。
第 5 步  验证并替换服务使用权重
Set-Location "E:\model\yolov5"
python val.py --data DFire.yaml --weights runs\train\dfire\weights\best.pt --device cpu
Copy-Item "E:\model\yolov5\runs\train\dfire\weights\best.pt" "E:\model\models\yolov5s-dfire.pt" -Force
server.py 直接加载 E:\model\models\yolov5s-dfire.pt；其类别 Fire、Smoke 会被程序统一转成小写 fire、smoke，与后端业务判断一致。
